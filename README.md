# ACKI MULTI MINER

An open-source mining application built with the Acki Nacki Bee SDK.

## Technologies
- React
- TypeScript
- Vite
- WebAssembly

## Network
Currently configured for Acki Nacki Shellnet.

## Installation
npm install

## Run
npm run dev

## Build
npm run build

## Project Status
Under development.
